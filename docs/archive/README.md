# Histórico preservado

A implementação ativa é o pacote Rust na raiz, derivado de `src/src/main.rs` da tag `baseline/pre-v1`. A tag e o [registro do baseline](../BASELINE.md) permitem comparar e recuperar todos os arquivos originais.

- [README original e sequência de patches](baseline-executor.md): contexto histórico; suas instruções/capacidades não substituem o README atual.
- `baseline-scripts/`: scripts originais, preservados para consulta. Não os execute a partir desta pasta; os scripts ativos ficam em `scripts/` na raiz.
- `experiments/responses-gpt-pro/`: tentativa experimental, excluída do build e sem papel canônico.
- [Handoff original](../crexe_handoff_docs/00_HANDOFF.md): descreve a proposta antiga; o plano atual prevalece.

Os dados e programas de outra máquina continuam na pasta local ignorada `docs/legado/TestesDeOutraMaquina/`, sem serem movidos ou publicados. As validações históricas continuam em `docs/validation/`.
