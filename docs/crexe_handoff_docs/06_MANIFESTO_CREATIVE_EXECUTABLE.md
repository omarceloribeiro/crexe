# CREXE Manifesto

## Creative Executable

CREXE means:

> Creative Executable

A CREXE file is not merely a script.  
It is not merely source code.  
It is not merely an installer.  
It is not merely a binary.

It is a creative executable specification.

---

## 1. Software should be regenerable

Software should not always be frozen into artifacts compiled elsewhere.

Some software should be distributed as intent and regenerated locally.

---

## 2. The user should be allowed to shape the tool

A CREXE file should not only run.

It should be editable.

The user should be able to:

- inspect the purpose
- edit the prompt core
- customize behavior
- redesign the UI
- regenerate the app

---

## 3. Native does not have to mean fixed

A single CREXE can produce:

- Win32 on Windows
- Cocoa on macOS
- GTK on Linux

The prompt can be single.

The outputs can be native.

---

## 4. Compatibility should be adaptive

Instead of asking one binary to survive every environment, CREXE asks the environment to build the right program.

Compatibility becomes regeneration.

---

## 5. Security must be part of the format

Creative execution without security becomes chaos.

CREXE runtimes must be:

- restrictive
- sandboxed
- auditable
- explicit
- signed when needed

---

## 6. Software can become a medium

Today, most people consume software.

CREXE imagines a world where people create software artifacts as naturally as documents.

A `.crexe` can be shared, forked, customized, and regenerated.

---

## 7. The future operating system may understand intent

In the long term, operating systems may not only run binaries.

They may run specifications.

Some system tools may be regenerated from creative executable descriptions.

Downloading an app may become downloading text.

---

## 8. Open enough to spread, strong enough to sustain a business

The best path is likely:

- open specification
- basic runtime
- premium studio
- secure runtime
- marketplace
- enterprise policies
- signing infrastructure

---

## 9. North star

> Download intent. Execute creativity.
